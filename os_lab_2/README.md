# ОС-лаба 2: TCP-сервер с обработкой сигнала через `pselect()`

Однопоточный однопроцессный TCP-сервер на C++17 для Linux. Он совмещает сетевые события и сигнал `SIGHUP` без гонок.

## Что делает

- Слушает порт **5000** и сообщает о новых подключениях.
- Держит **одно** клиентское соединение, остальные закрывает сразу после `accept`.
- Печатает количество полученных байт и сообщает об отключении клиента.
- На `SIGHUP` печатает сообщение и продолжает работать.
- На `SIGINT` (`Ctrl+C`) и `SIGTERM` (`kill PID`) корректно завершается.

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -g server.cpp -o server
./server
```

## Проверка

```bash
nc localhost 5000              # клиент: напечатайте текст
nc localhost 5000              # второй клиент будет закрыт
kill -HUP $(pgrep -x server)   # сигнал: сообщение, сервер работает дальше
```

## Как устроено

1. Слушающий сокет: `socket` → `SO_REUSEADDR` → `bind` → `listen`.
2. `SIGHUP`, `SIGINT`, `SIGTERM` блокируются через `sigprocmask` с сохранением исходной маски, затем через `sigaction` ставятся обработчики.
3. Обработчики только ставят флаг `volatile std::sig_atomic_t`.
4. Главный цикл ждёт все события одним `pselect` и передаёт ему исходную маску. Ядро атомарно разрешает сигналы на время ожидания, поэтому сигнал не теряется.
5. При `EINTR` цикл проверяет флаг и начинает новый виток. Иначе обрабатывает готовые дескрипторы: `accept` или `recv`.
6. Дескрипторы хранятся в RAII-классе `Fd`: `close` в деструкторе, копирование запрещено.
