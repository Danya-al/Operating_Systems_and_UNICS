# Лабораторная работа № 3. Жёсткие ссылки

Программа на C++17 рекурсивно обходит указанный каталог и вычисляет SHA-256 для каждого обычного файла. Если у нескольких файлов в одной файловой системе совпадает хэш, программа сохраняет один экземпляр и заменяет остальные жёсткими ссылками на него.

## Сборка и запуск

Для сборки в Ubuntu нужны компилятор `g++` и пакет `libssl-dev`. Выполните команды из каталога с `main.cpp`, указав при запуске путь к обрабатываемому каталогу.

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o dedup -lcrypto
./dedup /путь/к/каталогу
```

## Пример проверки

```bash
d=$(mktemp -d)
mkdir "$d/sub"
echo hello > "$d/a.txt"
cp "$d/a.txt" "$d/sub/b.txt"
echo other > "$d/c.txt"

./dedup "$d"
ls -i "$d/a.txt" "$d/sub/b.txt" "$d/c.txt"
./dedup "$d"
```

Первый запуск выводит `Создано жёстких ссылок: 1`. Команда `ls -i` показывает одинаковый номер inode у `a.txt` и `sub/b.txt`, а у `c.txt` — другой. При повторном запуске программа выводит `Создано жёстких ссылок: 0`.
